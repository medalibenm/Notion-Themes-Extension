# Coverage checklist

Run through this for every theme before a release, and after any Notion update.

- [ ] Sidebar, top bar, breadcrumbs, page background
- [ ] Page text, headings, links, muted text, placeholders
- [ ] Code blocks, inline code, quotes, callouts, toggles, dividers
- [ ] Database views: table, board, gallery, list, calendar, timeline
- [ ] Property tags and select colors (all 10 Notion colors)
- [ ] Menus: slash menu, context menu, block handles, color picker
- [ ] Modals and overlays: search, settings, share, page peek, comments
- [ ] Date picker
- [ ] Hover, selection and focus states, scrollbars
- [ ] Public pages on `*.notion.site`
- [ ] Login page on `app.notion.com/login`
