## Name

Tint for Notion

## Short description

Color themes for Notion on the web. Unofficial: not affiliated with or endorsed by Notion.

## Category

Productivity (Chrome: Workflow & Planning, if it asks for a subcategory)

## Detailed description

Give Notion a different look. Tint for Notion re-skins Notion on the web with color themes beyond the default light and dark.

Themes included:
• Nord
• Dracula
• Catppuccin Mocha
• Rosé Pine
• Solarized Light
• High Contrast

Features:
• Switch themes live from a small popup, with no page reload
• Every open Notion tab updates at once
• Themes cover pages, sidebars, menus, tags, callouts and code blocks
• Text colors are tuned for readable contrast
• Works whether Notion is set to light or dark
• Turn it off at any time with one switch

Private by design: Tint for Notion runs only on Notion pages, reads none of your content, and collects no data.

Tint for Notion is an unofficial extension. It is not affiliated with, endorsed by or sponsored by Notion Labs, Inc. "Notion" is a trademark of its owner, used here only to describe what the extension works with. It works in the browser only, not in the Notion desktop app.

## Single purpose (Chrome dashboard)

Applies color themes to Notion's web interface.

## Permission justifications (Chrome dashboard)

**storage:** Saves the user's chosen theme and on/off setting, so they persist and apply across Notion tabs.

**Host access (app.notion.com, www.notion.so, *.notion.site):** Injects the stylesheet and theme colors on Notion pages. The extension runs on no other sites.

**Remote code:** No. All code ships in the package.

## Data usage (Chrome dashboard)

Collects none of the listed data types. Certify all three limited-use statements.
